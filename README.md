# Enterprise Security Labs

This repository documents hands-on security labs simulating real-world
enterprise network and security architectures.

## 🎯 Objectives
- Design realistic enterprise network architectures
- Implement security controls (Firewall, DMZ, IAM, Proxy, DLP)
- Simulate attacks and analyze defensive mechanisms
- Build strong documentation and security reasoning skills

## 🧱 Lab Structure
Each lab follows a consistent structure:
- Context & security objective
- Architecture design
- Implementation details
- Attack simulation
- Defensive analysis & logs
- Lessons learned

## 📂 Lab Categories
- Network Foundations (LAN, DMZ, Firewall)
- Identity & Access Management (AD, Keycloak, MFA)
- Web Proxy & Data Loss Prevention
- SOC Visibility & Monitoring

## ⚠️ Disclaimer
These labs are built for educational purposes only and do not represent
production-ready configurations.

---

🧠 Focus: learning **why** security controls exist, not just **how** to configure them.
